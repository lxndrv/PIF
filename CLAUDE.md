## Project Overview

PIF (Proportional Interaction Framework) is a theoretical systems science framework documented entirely in Markdown. It proposes a unified lens for understanding how systems—physical, biological, cognitive, social—organize, interact, adapt, and transform through proportional relationships and threshold dynamics.

## Core Framework

**Three Universal Principles:**
1. **State** = Structure / Chaos (ratio determines system behavior)
2. **Interaction** = f(Impedance, Resonance, Scale) (compatibility determines effectiveness)
3. **Response**: Elastic if Load < Capacity; Phase Transition if Load > Capacity

**The Cycle:** State → Interaction → Response → New State (self-perpetuating emergence)
